## Problemas encontrados y correcciones

1. Enlaces Oracle para varias actualizaciones de JDK17 devolvieron 404. Se localizó la publicación oficial actual de Temurin 17.0.21+9 y se verificó su SHA-256 oficial antes de extraer. Se mantiene el requisito JDK17, sin cambiar la versión mayor autorizada.
2. La política de red rechazó páginas de documentación de developer.android.com/kotlinlang.org y alternativas de descarga no permitidas. No se eludió ni se amplió esa política. Los repositorios oficiales de artefactos accesibles y la compilación real permitieron continuar; no se atribuye lectura a páginas rechazadas.
3. Lint inicial: `DataExtractionRules`, `MissingApplicationIcon`, `SetTextI18n`. Se añadieron los recursos base y se actualizó Activity/manifiesto. La repetición final no suprimió reglas y quedó sin incidencias.
4. ADB aborta con `Cannot mkdir '/home/agent/.android': Read-only file system` (salida -6). Se probaron rutas Android de configuración escribibles sin alterar HOME; ese binario mantuvo la ruta de solo lectura. No se cambió el directorio personal ni se eliminaron datos. No se acredita un listado de dispositivos satisfactorio ni instalación.
