## Repetición

Usar los comandos y condiciones de [pruebas integradas](../PRUEBAS_INTEGRADAS.md) y la [batería completa anterior](P5-P8-2026-10-25.md#repetición). Ejecutar también:

```bash
.venv/bin/python -m unittest discover -s scripts/tests -v
.venv/bin/python scripts/check_contract.py
python3 scripts/check_postgres.py
python3 scripts/package_qa.py --native-report .tooling/android-native/7efb673fc2ea4d07 --output .tooling/delivery/NOMBRE_NUEVO.zip
```

Extraer el ZIP en una carpeta nueva, ejecutar `sha256sum -c SHA256SUMS` allí y seguir `LEEME.md`. Para reconstruir desde `source/`, preparar JDK21/SDK35 y ejecutar `python3 scripts/gradle.py :apps:agent:assembleDebug :apps:control:assembleDebug :backend:ktor:installDist --no-daemon --max-workers=1`. El verificador utilizado para la API extraída empleó el `.venv` fijado del proyecto, una copia QA y certificados de QA externos al ZIP.

Los logs crudos, respaldos y entradas privadas de instrumentación permanecen excluidos de Git. El paquete QA y sus checksums se generan solo después de verificar los hashes de las apps realmente instaladas.
